# Explainable and Multimodal Classification of Breast Cancer Histopathology Images

Magnification-aware deep learning framework for hierarchical breast cancer classification on the [BreaKHis dataset](https://web.inf.ufpr.br/vri/databases/breast-cancer-histopathological-database-breakhis/). Covers binary benign/malignant and 8-way subtype classification across three architectures, with Grad-CAM and occlusion-based interpretability.

**Authors:** Jonathan Brown · Zhuoyao (Martin) Xin · Sakshi Singhal · Nnemdi Amanambu  
Department of Biomedical Engineering, Johns Hopkins University

## Dataset

Download [BreaKHis v1](https://web.inf.ufpr.br/vri/databases/breast-cancer-histopathological-database-breakhis/) and point each module's config to your local path. All modules use the same normalization: mean `[0.485, 0.456, 0.406]`, std `[0.229, 0.224, 0.225]`. Metadata CSV is generated by the ResNet preprocessing step.

---

## Results Summary

| Architecture | Image AUC | Patient Accuracy | FNR |
|---|---|---|---|
| ResCNN (baseline) | 0.836 | 91.4% | 8.8% |
| ViT-Small | 0.932 | 94.1% | 2.1% |
| Swin-Tiny | 0.830 | 94.1% | 4.0% |

All architectures use learnable magnification token embeddings and majority-vote patient-level aggregation. See individual READMEs for subtype results and training details.

## Quickstart

Each module has its own setup — see the subfolder README. All notebooks are configured for Google Colab with Google Drive mounted. Python ≥ 3.8, PyTorch ≥ 1.12, GPU recommended.  

```bash
# ResNet baseline (local)
cd breakhis_rescnn_project
pip install -r requirements.txt
python scripts/example_run_5fold.py
```

For ViT, Swin, and explainability, follow the Colab setup in the respective READMEs.
